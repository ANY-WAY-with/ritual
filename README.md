# Ritual

The public Ritual website at https://madeinritual.com, made by Rhetoric.

## Development

Use Node.js 24 (`.nvmrc`), then run `npm ci` and `npm run dev`.
Run `npm run check` before pushing. The site currently needs no environment variables.

## Deployment

GitHub: https://github.com/ANY-WAY-with/ritual
Vercel: ANY-WAY team, `ritual` project. Production branch: `main`.
Domain registrar and authoritative DNS: GoDaddy. Primary domain: `madeinritual.com`.
`www.madeinritual.com` redirects to the primary domain.

The launch page provides a working contact email; product login and signup are not connected yet.
