## Proposed first science scene

The hero names the Science explainer workspace and the project, “Why do rockets launch east?” The stage has three types of material a creator would keep open.

- A selected SpaceX clip provides the opening image.
- A NASA source note supports the explanation of Earth’s rotation.
- A draft script shows the creator’s own note about explaining the spinning launchpad before introducing the orbit.

The primary interaction opens one reference and shows where the creator uses it in the draft. The outer items can continue to suggest the depth of the current hero. The main work stays readable and has a visible project name. On a narrow viewport, prioritize the project and the selected reference before the surrounding materials.

An optional short demonstration could follow a creator opening the launch footage, marking the useful moment, and rewriting one line. Choose a clip where a single task and its outcome are legible. The source footage, its evidence, and the creator’s decisions each have a specific place in the scene. These are proposals for the next iteration.
